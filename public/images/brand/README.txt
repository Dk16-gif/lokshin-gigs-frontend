Lokshin Gigs — web logo assets

Files
- lokshin-gigs-horizontal.png: high-resolution transparent master for light surfaces.
- lokshin-gigs-horizontal.webp: optimized 1600px-wide version for normal web use.
- lokshin-gigs-horizontal-1000.webp: medium version.
- lokshin-gigs-horizontal-600.webp: compact version.
- lokshin-gigs-horizontal-dark-bg.png / .webp: wordmark and tagline in warm ivory for dark surfaces.
- lokshin-gigs-mark.png / .webp: emblem-only square mark with an opaque cream badge face.
- lokshin-gigs-favicon.png: 64px square icon source.

Guidance
- Prefer WebP for page content; use the transparent PNG master when needed.
- Light version is for cream/light surfaces; dark-bg version is for espresso/dark surfaces.
- The circular badge face is solid warm cream; the outside of the artwork is transparent.
- Use the full horizontal logo only where it has enough height for the tagline to remain legible. On narrow/mobile headers, use the emblem with accessible text or a compact variant rather than shrinking the full lockup too far.
- Preserve aspect ratio (width: 100%; height: auto; object-fit: contain).
- Suggested starting point: .site-logo { display:block; width:clamp(190px, 22vw, 300px); height:auto; }
- These are raster web assets, not editable vector/SVG masters. Review before production-wide integration.
