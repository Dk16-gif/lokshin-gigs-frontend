# Lokshin Gigs — Homepage Image Manifest

Image assets on the homepage come from three sources:

1. **User-provided local assets** — hand-supplied images that must not be
   overwritten. They are NOT listed in `scripts/home-image-slots.json` and the
   fetcher is unaware of them.
2. **Pexels-fetched images** — downloaded by `scripts/fetch-home-images.mjs`
   according to the slots in `scripts/home-image-slots.json`, subject to the
   relevance filter (anchors / prefer / reject). The table below is
   auto-regenerated by the fetcher on each run with matched subjects,
   photographers, sources, and licences.
3. **On-brand placeholder tiles** — warm ivory tiles labelled by category, kept
   for any slot where the relevance gate rejected every candidate.

To replace any of these later, drop a new file at the same path (any reasonable
size / aspect ≥ 5:4). The homepage will pick it up on next page load. Do NOT
re-add these filenames to `home-image-slots.json`.

## Pexels-fetched slots

The full generated table (file · category · matched subject · query used ·
photographer · source · licence) appears here after the fetcher runs. Skim the
**Matched subject** column to audit relevance.

The `printing-flyers.jpg` slot for "Posters & pamphlets — flyer printing" is
currently an on-brand placeholder awaiting either a Pexels fetch or a
user-provided image. Fetch it via:

```
node scripts/fetch-home-images.mjs --force --only=printing-flyers.jpg
```
